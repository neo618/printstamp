# 📮 PDF 透明 PNG 电子印章工具

> 纯前端实现的 PDF 盖章工具，安全本地处理，高清无水印导出

---

## 🎯 项目概述

面向个人办公、行政人员使用的网页工具，实现：
- ✅ 上传普通 PDF 文件 + 透明底 PNG 印章图片
- ✅ 支持 PDF 多页翻页、指定页码跳转
- ✅ 将印章自由拖拽至 PDF 任意页面任意位置
- ✅ 内置固定印章物理尺寸：38mm、40mm、42mm
- ✅ 印章模板保存、重命名、删除管理
- ✅ 高清无水印导出盖章后的 PDF

## 📋 功能说明

### 1. 印章模板管理

- ✅ 上传透明底 PNG 格式印章图片
- ✅ 自动保存到本地模板库（localStorage）
- ✅ 支持重命名、删除操作
- ✅ 永久留存，随时调用

### 2. PDF 文件上传与校验

- ✅ 支持上传常规 PDF 格式文件
- ✅ 加密 PDF 不处理（需用户自行解密）
- ✅ 在线预览完整文档布局

### 3. PDF 多页浏览

- ✅ 上一页、下一页翻页
- ✅ 输入页码直接跳转
- ✅ 精准展示 A4 版式画布

### 4. 印章放置与尺寸

- ✅ 自由拖拽放置到任意位置
- ✅ 强制等比例缩放，不变形
- ✅ 固定尺寸：38mm、40mm（默认）、42mm
- ✅ 自动适配 A4 纸张比例

### 5. PDF 导出

- ✅ 生成全新 PDF，不覆盖原文件
- ✅ 无任何水印
- ✅ 保留原图清晰度
- ✅ 浏览器直接下载

## 📝 使用说明

### 第一步：上传印章

1. 点击左侧「上传新印章」按钮
2. 选择透明 PNG 格式的印章图片
3. 输入印章名称（如：公司公章）
4. 印章自动保存到模板库

### 第二步：上传 PDF

1. 点击或拖拽 PDF 文件到上传区域
2. 等待 PDF 加载完成
3. 预览确认文档正常

### 第三步：盖章

1. 从左侧模板库选择印章
2. 选择印章尺寸（38/40/42mm）
3. 在 PDF 上点击放置印章
4. 拖拽调整位置
5. 可翻页到多页盖章

### 第四步：导出

1. 点击「导出盖章 PDF」按钮
2. 浏览器自动下载新 PDF
3. 原文件不被修改

## 🔒 安全说明

- **纯前端处理**：所有操作在浏览器本地完成
- **文件不上传**：PDF 和印章不会上传到任何服务器
- **本地存储**：印章模板保存在浏览器 localStorage
- **原文件保护**：导出生成新文件，原文件不被修改
